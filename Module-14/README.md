# Module 14 – Capstone Project

## NeuroLearn AI
**Generative AI–Powered Personalized Learning and Classroom Support System**

This module documents our capstone project, NeuroLearn AI, a prototype designed to support personalized learning for autistic elementary-school students while keeping teachers involved in decisions about AI-generated classroom content.

### Project goals
- Explore personalized activities and hints based on fictional student profiles.
- Give students a simple way to request assistance.
- Provide teachers with a dashboard for reviewing and resolving help requests.
- Require teacher review and approval before AI-generated lesson adaptations are shown to students.

### Prototype and tools
Our prototype uses Python and Gradio in Google Colab. Work to date includes student and teacher screens, an in-memory help-alert queue, mock JSON profiles, and initial testing of generative hints through a hosted language-model API.

### Human-in-the-loop approach
AI is intended to assist, not replace, teachers. Generated suggestions should be reviewed by an educator before classroom use. Student profiles used in development are fictional.
