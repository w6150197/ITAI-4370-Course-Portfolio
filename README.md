## Selected project highlights

- BPSK signal modulation, noisy channel, and demodulation
- RF free-space path loss and Wireshark packet inspection
- Random Forest traffic prediction, anomaly detection, and clustering
- 5G slice resource allocation and Open RAN concepts
- Time-series forecasting and constrained edge AI
- Security and sustainable network operation
- Midterm: SimPy routing, Mesa agent-based modeling, and regression-based route selection
- 6G: terahertz, federated learning, AI-native architecture, and digital twins

## Evidence of growth

**Communication signals → network architecture → Python simulation → ML modeling → network optimization → edge, security and sustainability → 6G AI-native systems.**
